# Study With Focus

暗色毛玻璃风格番茄钟专注学习工具，视频背景 + 悬浮时钟。

## 功能

| 模块 | 说明 |
|------|------|
| 🍅 番茄钟 | 25 分钟专注 / 5 分钟休息，科目选择，分段学习记录 |
| 📅 学习日历 | 热力图日历，每日学习计划管理 |
| ✅ 待办列表 | 任务管理，支持置顶、完成标记 |
| 🛡️ 网络屏蔽 | hosts 文件拦截，专注时自动开启 |
| 📊 统计 | 学习时长、番茄完成数统计 |
| 📋 学习记录 | 按周查看分段学习数据，AI 专家评价 |
| 🎨 主题 | 8 种预设主题色 + 自定义颜色，3 个视频背景 |

## 特色

- **实时时钟**：基于 Date.now()，后台标签页计时不漂移
- **专注模式**：一键全屏 + 启动番茄钟 + 开启屏蔽
- **状态持久化**：刷新/关闭后恢复番茄钟进度（30 分钟有效）
- **科目分段记录**：切换科目自动记录上一个科目学习时长
- **提示音**：阶段切换自动播放

## 技术

- 纯前端 HTML/CSS/JS，无框架
- 后端 Python server.py（端口 8765）提供学习记录 API
- hosts 屏蔽通过 Python 脚本修改系统 hosts 文件
- 专家评价由 cron 定时调用 AI 生成

## 使用

```
# 启动后端
python server.py

# 浏览器打开 index.html
```
